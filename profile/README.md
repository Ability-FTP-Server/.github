# Ability FTP Server

> Ability FTP Server keeps a local server on one Windows desk: open the virtual folders, read the user list, and leave the site log on the same local server.

## Four Beats

1. **Name the server.** Give the Ability FTP Server local server a short title before you publish a path you do not run.
2. **Pin the live folders.** Keep current paths on Ability FTP Server virtual folders and leave unused sites aside.
3. **Read the users.** Open Ability FTP Server user list only for machines and folders the reader is authorized to run.
4. **Check the log.** Read Ability FTP Server site log before you archive a share.
5. **Keep the pair.** Leave folders and users on the same Ability FTP Server local server.
6. **Leave the log ready.** Keep the site log aligned with Ability FTP Server virtual folders.
7. **Read the server again.** Open Ability FTP Server user list if the path still looks crowded.
8. **Close the loop.** Clear finished paths so the next Ability FTP Server visit does not start with a search.

## First Questions

**Does Ability FTP Server replace every other program?**
No. Ability FTP Server sits beside the file desk, browser, and local hosts you already run.

**Can two people share one computer?**
Yes. Each person keeps a separate Ability FTP Server profile.

**What should a new user try first?**
One small Ability FTP Server virtual folder today, then the same site log tomorrow.

**Does the site log leave the local server?**
No. Ability FTP Server site log stays with Ability FTP Server user list on that server.

**Which folders belong on this local server?**
Only machines and folders the reader is authorized to run. Ability FTP Server is a local site you operate, not a door into a host you do not own.

**Is Ability FTP Server only for a finished share?**
No. Ability FTP Server can hold a single virtual folder while the rest of the office stays off the board.

**Will the next admin still see the user list?**
Yes. A named Ability FTP Server local server keeps users attached to the log.

## Field Note

Ability FTP Server is easier to trust when the local server stays smaller than the folder it came from. A named server shows what is active, the folder pins show which path is live today, and the closing note tells the next admin which user changed.

Keep that server on machines and folders the reader is authorized to run. The virtual folder map is a desk record for a local host you operate.

## One Real Pass

Pick a server that already has a name. Open it in Ability FTP Server, keep only authorized folders on the list, and finish one site log you can see.

If the pass feels crowded, the set is too wide. Drop anything that belongs to a different host and leave it out of this Ability FTP Server local server.
